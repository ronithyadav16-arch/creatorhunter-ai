# FrameForge AI

A free, browser-first video planning workspace for creators. Includes prompt-to-storyboard demo, scene prompt editing, script and caption drafts, templates, local project saving, brand kit, and JSON/text exports.

## Run locally
Open `index.html` in a modern browser. No package install, API key, server, or paid service is required.

## Deploy
GitHub Pages can host this static website for free. Enable Pages in repository settings and select GitHub Actions, or use the included workflow.

## Important limitation
This is a planning/demo tool. It does not render real AI video footage. A real generation model would need to be integrated separately and may have usage limits or costs. Project data is stored in local browser storage and does not sync across devices.

## Stack
Plain HTML, CSS, and JavaScript to avoid build steps and dependency costs.
